# Student Registration Form

This project is a simple web application that allows students to register themselves by providing their roll number and course. Students can also view all the registered data.


## Features

- Students can register by entering their roll number and course.
- Students can see all the registered data in a tabular format.
- All registered students' data will be displayed in a table below the registration form.
- Students can edit their data.
- Students can delete their data.

## Technologies Used

- HTML: For the structure of the web pages.
- JavaScript: For the functionality and interaction of the web pages.
- Bootstrap: For responsive and attractive styling of the web pages.
- Firebase Realtime Database: For storing and retrieving the registered student data.
- Git: For version control and project management.

## Getting Started
### Prerequisites
- A Firebase account.
- Node.js and npm (for installing Firebase CLI).

### Firebase Setup
1) Go to the Firebase Console.
2) Create a new project or select an existing project.
3) Add a new web app to your project:
    - Go to the project overview.
    - Click on the </> icon to add a new web app.
    - Register your app and follow the instructions to get your Firebase configuration.

## Project Setup
1. Clone the repository to your local machine:
    ```sh
      git clone https://github.com/Abbas2003/Registration-Form.git
      cd student-registration-form 
    ```
2. Include the Firebase SDK and initialize Firebase with your project configuration in your HTML file.
3. Implement the student registration form and data retrieval in your HTML and JavaScript files.

## Running the Project
- Open index.html in your web browser.
- Register a student by filling out the form and submitting it.
- View all registered students in the table below the registration form.
